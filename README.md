# 备忘录

本仓库用于分发备忘录 Android 安装包和软件内更新信息。

## 安装

在 [最新版本](https://github.com/zhu1148/notebook-releases/releases/latest) 下载 `memo.apk`，在安卓手机上安装。

已经安装旧版时，直接覆盖安装，不要先卸载；覆盖更新会保留笔记、标签和心情。

## 软件内更新

从 1.0.5 开始，软件支持启动后自动检查更新，也可以在“设置 → 检查更新”手动检查。

发现新版本后，可以查看说明、下载安装包，再由安卓系统完成安装确认。下载支持取消和重试。

安装前会检查大小、SHA-256、包名、版本和应用签名。笔记数据始终保存在本机；更新请求不上传笔记或备份。

## 更新文件

- `memo.apk`：该版本安装包。
- `update.json`：版本号、更新说明、安装包地址及校验值。

更新入口：https://github.com/zhu1148/notebook-releases/releases/latest/download/update.json

GitHub 的访问和下载速度取决于手机网络。软件内的说明/确认使用统一玻璃界面，安装授权和安装确认由安卓系统提供。
